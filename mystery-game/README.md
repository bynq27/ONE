# 古代推理游戏（暂定名）

宋代背景的推理断案游戏：现场勘验 → 走访取证 → 公堂对质。主画风是皮影戏，揭穿真凶的高潮时刻切换为水墨。

这个文件夹和仓库根目录的「合成塔防」是两个独立项目。以后有了单独的仓库，可以把整个文件夹搬过去。
